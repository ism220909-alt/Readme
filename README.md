Консольное приложение для учёта прочитанных книг.

Функции:
- Добавить книгу (автор, название, оценка 1–5, дата)
- Показать все книги
- Показать среднюю оценку
- Статистика по авторам
- Удалить книгу

Данные хранятся в books.json.

Запуск:
python main.py

Пример:
1 -> ввод полей -> книга сохранена
2 -> показать все книги
